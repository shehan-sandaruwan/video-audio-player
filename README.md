# Video & Audio Player Demo

A mock application demonstrating a custom video and audio streaming player, built as a proof-of-concept from a previous project at xinoTech.

## Overview

This project showcases a robust streaming player implemented using the **HLS.js** library to parse and manage adaptive bitrate streams. The player itself is built on the native **HTML5 Video element**, utilizing its built-in controllers for a familiar user experience.

## Key Features

- **HLS Streaming Support:** Efficiently plays HLS streams using the HLS.js library.
- **HTML5 Video Player:** Leverages the standard, cross-browser compatible HTML5 video player.
- **Demo Playlist:** A list of sample streams is provided for easy testing.
- **Basic Error Handling:** Includes mechanisms to catch and handle common playback errors.

## Technology Stack

- **Framework:** Next.js
- **Streaming Library:** HLS.js
- **Player:** Native HTML5 Video Element
